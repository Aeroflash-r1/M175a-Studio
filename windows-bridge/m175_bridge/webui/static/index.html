Phone setup

Printing: Android Settings → Connected devices → Printing → Default Print Service (or Mopria) → the printer appears automatically on this Wi-Fi. Or Add printer by IP: http://THIS-PC:8080/ipp/print

Scanning: install Mopria Scan (or any eSCL/AirScan app) → the scanner appears automatically. Apps like "Fast Scanner (eSCL)" also work.
